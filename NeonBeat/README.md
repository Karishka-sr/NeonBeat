# NeonBeat — ритм-игра для Android (Kotlin)

Четыре (или до семи) дорожки, ноты падают вниз, ты попадаешь в такт. Музыка сочинена кодом и звучит
без единого аудиофайла внутри APK.

## Что внутри игры

- **5 встроенных песен**: Neon Horizon, Pixel Rush, Midnight Drive, Gravity Wave, Hyperdrive.
- **5 сложностей** на каждую песню: Лёгкая, Нормальная, Сложная, Эксперт, Безумие.
  Чем выше сложность, тем плотнее ноты, больше аккордов и длинных нот, строже окна попадания.
- **Оценки**: PERFECT / GREAT / GOOD / MISS, комбо, шкала здоровья, очки до 1 000 000, ранги SS / S / A / B / C / D / F,
  лучшие результаты запоминаются.
- **Редактор карт**:
  - тап по дорожке ставит или убирает ноту, долгий тап и протяжка делают длинную ноту;
  - щипок двумя пальцами меняет масштаб, справа полоса перемотки;
  - сетка с делениями (привязка нот к долям), метроном, звук попаданий, замедление воспроизведения;
  - **REC**: играешь песню пальцами, ноты записываются сами;
  - **автозаполнение**: для встроенной песни — как в игре, для своего аудиофайла — по ударам в музыке;
  - можно сделать карту без музыки, со встроенной песней или со своим mp3 / ogg / wav / m4a;
  - тестовая игра прямо из редактора.
- **Свои карты**: поделиться текстом, сохранить файл `.nbm`, импортировать из буфера обмена или из файла
  (карту можно отправить другу в Telegram).
- **Настройки**: громкость музыки и звуков, скорость нот, положение линии попадания, ширина поля,
  затемнение фона, вибрация, шкала точности, подписи EARLY / LATE, 4 цветовые темы,
  режимы «без проигрыша» и «автоигра».
- **Калибровка задержки**: метроном и тапы, игра сама считает задержку твоего телефона.

## Как получить APK (без Android Studio)

Android Studio на Windows 7 не запустится, поэтому APK собирает бесплатный сервис GitHub.
Всё делается в браузере.

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **+** вверху справа → **New repository**. Назови, например, `NeonBeat`.
   Поставь **Public** и нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Распакуй этот архив на компьютере. Перетащи в окно браузера **всё содержимое папки `NeonBeat`**
   (папки `app`, `gradle`, `.github` и файлы `build.gradle`, `settings.gradle`, `gradlew` и остальные).
   Нажми **Commit changes**.

   > Папка `.github` начинается с точки, и Windows может её скрыть. Если после загрузки
   > в репозитории нет `.github/workflows/build.yml`, смотри раздел «Если нет папки .github» ниже.

5. Открой вкладку **Actions**. Сборка запускается сама после загрузки.
   Если её нет, выбери слева **Build APK** → **Run workflow** → **Run workflow**.
6. Подожди 3–6 минут, пока рядом с запуском не появится зелёная галочка.
7. Открой этот запуск и внизу, в разделе **Artifacts**, скачай **NeonBeat-apk**.
   Это zip, внутри два файла: `app-release.apk` и `app-debug.apk`.
8. Перекинь `app-release.apk` на телефон (по USB, через Telegram или облако) и открой его.
   Android спросит про установку из неизвестных источников — разреши для того приложения,
   из которого открываешь файл (Файлы, Telegram и т. д.).

APK подписан отладочным ключом. Для личной игры этого хватает. Для публикации в Google Play
понадобился бы свой ключ.

### Если нет папки .github

В репозитории нажми **Add file → Create new file**. В поле имени набери
`.github/workflows/build.yml` (слэши создадут папки сами) и вставь:

```yaml
name: Build APK

on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Build
        run: |
          chmod +x gradlew
          ./gradlew assembleRelease assembleDebug --no-daemon --stacktrace

      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: NeonBeat-apk
          path: |
            app/build/outputs/apk/release/*.apk
            app/build/outputs/apk/debug/*.apk
```

Нажми **Commit changes**, сборка запустится.

### Если сборка упала (красный крестик)

Открой запуск → шаг **Build** и скопируй последние ~50 строк лога. Пришли их мне, я исправлю код.
Проект ни разу не собирался настоящим Android-сборщиком (в моей среде он недоступен),
поэтому первая сборка может потребовать правки.

## Как играть

- **Меню → ИГРАТЬ**: выбери песню и сложность (в клетке видны уровень и твой лучший ранг).
- Нажимай на дорожку, когда нота доходит до линии. Длинную ноту держи до конца.
  Можно нажимать несколькими пальцами.
- **Звук опаздывает или спешит?** Открой Настройки → Калибровка задержки.
- **Меню → РЕДАКТОР КАРТ → + Новая карта**: задай название, число клавиш (4–7), музыку и BPM, потом ставь ноты.
  В редакторе кнопка меню содержит автозаполнение, привязку к сетке, справку и сохранение.

## Устройство проекта

| Папка / файл | Что там |
|---|---|
| `app/src/main/java/.../core/` | Игровое ядро без Android: движок оценок, композитор и синтезатор песен, генератор карт, поиск ударов в аудио, формат карт |
| `app/src/main/java/.../audio/` | Декодирование аудиофайлов, точные часы по звуку, звуки попаданий |
| `app/src/main/java/.../ui/` | Все экраны: меню, выбор песни, игра, результаты, настройки, карты, редактор |
| `Env.kt`, `MainActivity.kt` | Хранилище настроек, рекордов и карт; главное окно |
| `.github/workflows/build.yml` | Сборка APK на GitHub |

Внешних библиотек нет: только Kotlin и сам Android. Интерфейс нарисован кодом (View и Canvas),
без XML-разметки и без Compose.

Минимальная версия Android — 7.0 (API 24). Игра только в портретной ориентации.

## Формат файла карты (.nbm)

Обычный текст, его можно править в блокноте:

```
NEONBEAT-MAP 1
title=Моя карта
artist=Я
bpm=128.0
offset=0
keys=4
audio=builtin:neon_horizon
length=60000
notes:
1234,0        ← нота: время в мс, номер дорожки (с нуля)
1500,2,400    ← длинная нота: время, дорожка, длительность в мс
```

`audio` может быть `builtin:<id песни>`, `file:<имя файла>` или пустым (без музыки).
